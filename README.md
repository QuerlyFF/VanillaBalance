# VanillaBalance

Плагин баланса ванильных механик для Paper 1.21.1 и Java 21.

Сборка и тесты: `mvn clean verify`. Готовый плагин: `target/VanillaBalance.jar`.

Настройки находятся в `src/main/resources/config.yml`. Примеры настроек Paper — в `paper-config/`. Подробное описание механик и команд — в [README_RU.txt](README_RU.txt).

Проект выделен из [SMPCristalix](https://github.com/QuerlyFF/SMPCristalix) с сохранением истории изменений плагина.
