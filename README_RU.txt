VanillaBalance 1.0.0 — Paper 1.21.1 / Java 21
================================================

УТВЕРЖДЁННЫЙ БАЛАНС
-------------------
1. Все руды: -15% только при генерации новых чанков.
2. Paper Anti-Xray: engine-mode 3; VanillaBalance проводит полный аудит per-world настроек.
3. Heavy Core из ominous vault: дополнительный -20% после ванильного roll.
4. Elytra: случайный шанс 1/3 прямо при генерации End City. Никаких счётчиков и сканирования рамок игроков.
5. Iron Golem: железо -50% (оставлено по решению владельца).
6. Натуральный ванильный XP: x0.5. Дробный остаток хранится в PDC игрока и переживает logout/restart.
7. Жители: будущие физические монеты через CoinProvider; пока провайдера нет, трейды блокируются.

ОПТИМИЗАЦИЯ ПРЕГЕНА
-------------------
Старый вариант проверял примерно 98 304 блока на Overworld-чанк.
Новый OreSampler использует геометрические пропуски и делает getType() только примерно для 15% позиций.
В среднем это около 14 746 проверок вместо 98 304 — примерно в 6.7 раза меньше тяжёлых region lookup.
Статистическая вероятность удалить каждый блок руды остаётся 15%.

ЭЛИТРЫ
------
Используется Paper AsyncStructureGenerateEvent + EntityTransformer.
Решение 1/3 делается до появления естественного ItemFrame в мире.
Player-placed рамки вообще не участвуют.
Старые уже сгенерированные End City не меняются — это намеренно, так как мир будет прегенерирован с плагином.

ЖИТЕЛИ
------
CoinProvider создаёт настоящий ItemStack монеты.
VanillaBalance открывает временный Merchant-клон с монетными ценами и не записывает монетные рецепты в NPC.
uses/demand/maxUses синхронизируются обратно в ванильные рецепты при закрытии.
Опыт профессии обычного Villager тоже переносится, и при достижении ванильного порога открывается следующий уровень.

ANTI-XRAY
---------
Проверяются effective-настройки default + paper-world.yml override для каждого загруженного Overworld/Nether:
- enabled
- engine-mode
- max-block-height
- update-radius
- use-permission
- обязательные hidden-blocks
- обязательные replacement-blocks

Команды:
/vb status
/vb antixray
/vb reload

Сборка/тесты:
mvn clean verify

Результат:
target/VanillaBalance.jar
